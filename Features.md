* **ammo** - limited ammo system contains 3 different ammo reload system purely based on server side. 

* **dynamic-magazine** - added dynamic magazine's which admin can create magazine to player and player can buy or craft magazine which can be bigger than even client magazine size. 

* **td** - ammo , reserve , magazine size weapon object existing textdraw 

* **dynamic weapon object** - dynamic weapon object attached when player hits 0 ammo to give realism and this object can be use like a real weapon /dropgun, /sell, etc would work

* **dynamic weapon reload** - dynamic reload acording to weapon

* **dynamic weapon switch** - realistic weapon switch throuch weapon objects

* **colorchanging td** - color change in td according to the ammo the weapon have.
